## Core Capabilities vs Product Scope

The 27 capabilities above divide into three categories:

### Core SHUNYA capabilities (should be in canonical)
These are fundamental to the OS product experience:

| Capability | Priority | Reason |
|---|---|---|
| **Create object** | High | Living Objects section exists but cannot create objects |
| **View object detail** | High | LivingObjectCard shows summary but not full detail |
| **Search** | High | An operating system must be searchable |
| **Task management** | High | Execution commitments need task tracking |
| **AI chat** | Medium | Observations are good; conversation is better |
| **File management** | Medium | Files are fundamental objects |
| **Team management** | Medium | Collaboration requires teams |

### Business vertical capabilities (integrations layer)
These are domain-specific and belong to business verticals, not the core OS:

| Capability | Notes |
|---|---|
| Create proposal | Belongs in a `Proposal` workspace/object, not the OS itself |
| Manage invoices | Same — invoice is a domain object |
| Manage contacts | Contact is a Living Object relationship — covered by relationship model |
| Sales pipeline | Sales is a vertical; pipeline visualization is an integration |
| Finance overview | Finance is a vertical |
| Marketing view | Marketing is a vertical |
| Reports panel | Reporting is a cross-cutting capability, not a core panel |

## EP-01 Closure Assessment

EP-01 requires: "Every legacy capability has a canonical replacement. Every replacement is verified. Every consumer has migrated."

**Core capabilities still missing:**
1. **Create object** — Living Object Cards exist but no creation flow
2. **View object detail** — Cards show summary only
3. **Search** — Not implemented
4. **Task management** — Not implemented (CommandSurface is commands, not tasks)
5. **AI chat** — Observations are one-way; no conversational interface

**These capabilities block EP-01 closure** because their legacy expressions existed and real users may have depended on them.

**Recommendation:** Before declaring EP-01 complete, implement the five missing core capabilities in the canonical workspace. The 22 remaining capabilities (business verticals + external integrations) can be deprecated as legacy scaffolding that predates the canonical Living Workspace architecture.

**Migration plan for missing core capabilities:**
1. Object creation → Add creation flow to Living Objects section
2. Object detail → Expand LivingObjectCard with expandable detail view
3. Search → Add search input to TopBar, integrated with Reality Engine
4. Task management → Integrate Commitment Runtime with canonical workspace
5. AI chat → Extend AIPresencePanel with reply capability
