# G1.1-R6B-1 Test Environment Integrity

## Invariant

```
TEST PROCESS
    ↓
DATABASE CONFIGURATION
    ↓
IDENTITY VALIDATION
    ↓
IF NOT ISOLATED TEST DB
    ↓
FAIL CLOSED
```

## Implementation

Guard in `tests/conftest.py` — evaluated at pytest import time, before any test executes.

**Rejects:**
- Missing `DATABASE_URL` (empty/unset)
- Production PostgreSQL (`shunya` + `postgresql://` pattern)
- Any PostgreSQL without explicit sqlite override (`postgresql://` detected)
- Remote PostgreSQL (catches all `postgresql://` automatically)
- `.env` fallback to production (guard overrides fail closed)

**Permits:**
- `sqlite:///:memory:` — canonical isolated test DB
- `sqlite:///path` file-based SQLite (without `shunya` in the path)
