# G1.1-R4: Execution Ownership Audit

**Date:** 2026-09-02  
**Status:** VERIFIED

## When SHUNYA decides something should happen, what single production runtime owns the execution?

**Canonical execution authority:** `app/runtime/entry.py` → `process_event()` → `app/execution_engine/` → `OutcomeRuntime`

---

## Observation → Execution Chain

```
Observation (external event or internal trigger)
    │
    ▼
process_event() in app/runtime/entry.py
    │  Reads entity from `Object` (working memory)
    │  or canonical business object from sh_objects
    │
    ▼
ConstitutionalDecisionEngine (app/execution/decision.py)
    │  Evaluates: is execution authorized? is intent valid?
    │  Creates DecisionTrace record
    │
    ▼
ExecutionService in app/execution/runtime.py (OutcomeRuntime)
    │  Creates Execution record
    │  Runs the actual business logic
    │
    ▼
Execution result
    │  Creates ExecutionLog record (evidence)
    │
    ▼
Resulting observation (next event trigger or completion notification)
    │
    ▼
Updated context (new Object state or event on business object)
```

## No Phantom Engine — No Duplicate Executor — No Bypass

**Previously (pre-G1.1-R4):**
- `core/execution_runtime/` was wired into the pipeline via `ExecutionRuntimeAdapter`
- 7 intelligence runtimes had `register_execution_actions()` methods with phantom imports
- The adapter always returned "noop" because no production actions were registered

**Now:**
- `core/execution_runtime/` is fully decommissioned from the pipeline
- All `register_execution_actions()` methods removed from 10 intelligence runtimes
- The canonical execution path (`app/runtime/entry.py` → `execution_engine`) is the ONLY production execution authority
- `test_prod06_execution_engine.py` proves the execution chain end-to-end

## Execution Authority Map

| Concept | Owner | Status |
|---------|-------|--------|
| Execution intent | `app/runtime/entry.py:process_event()` | ✅ CANONICAL |
| Decision (constitutional) | `DecisionTrace` | ✅ CANONICAL |
| Execution runtime | `OutcomeRuntime` (app/execution/runtime.py) | ✅ CANONICAL |
| Execution state | `Object` table (working memory) | ✅ CANONICAL |
| Execution evidence | `ExecutionLog` | ✅ CANONICAL |
| Legacy execution | `core/execution_runtime/` | 🗑️ DECOMMISSIONED |

### Failure semantics

| Scenario | Behavior | Tested |
|----------|----------|--------|
| Invalid execution request | Rejected by ConstitutionalDecisionEngine | ✅ test_prod06: TestExecutionSemantics |
| Duplicate execution | Inflight detection prevents concurrent execution | ✅ test_prod06: TestConcurrentSameEntity |
| Authorization failure | Decision engine denies execution | ✅ test_prod06: TestDecisionNegation |
| Execution failure | ExecutionLog records failure truthfully | Built into execution flow |
| Partial execution | ExecutionLog records partial state | Built into execution flow |
| Retry | Re-run process_event for same entity | Via entity_id idempotency |
| Recovery | State machine transitions via events | Via Object state transitions |
| Execution failure produces truthful evidence | ExecutionLog records error state, not success | ✅ verified via test |
