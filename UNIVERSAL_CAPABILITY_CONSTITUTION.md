## Part III — Constitutionally Removed: Justification

The 13 Constitutionally Removed capabilities are all domain-specific verticals that SHUNYA serves through **Universal Ontology composition** (Z-05) rather than custom implementation. For example:

- **Healthcare** → Person + Organization + Event + Observation + Document compose any healthcare workflow
- **Education** → Person + Organization + Commitment + Event + Knowledge + Observation compose any education workflow
- **Manufacturing** → Asset + Commitment + Workflow + Event compose any manufacturing workflow
- **Real Estate** → Asset + Place + Commitment + Person compose any real estate workflow

These are not "missing" — they are intentionally designed to be composed from the 18 universal concepts. Adding custom vertical screens would violate the constitutional principle of business-agnostic architecture (Z-05, Z-08 Art III).

Future vertical expansion must be achieved through ontology composition + AI understanding + workspace templates, never through new object types.
