# EX-02-R2 — Constitutional Conformance Discipline

**Established by:** Founder directive, 2026-08-05 (CDR-006 review)
**Amends:** EX-02, EX-02-R1, LX-06D-R3 (CDR mandatory sections)
**Status:** Locked — permanent addition to CDR methodology

---

## 1. The Principle

A Constitutional Discovery Report shall never derive constitutional truth from the repository.

The **Constitution** defines SHUNYA.
The **Repository** demonstrates SHUNYA's current conformance to that Constitution.

These two authorities shall remain permanently independent.

---

## 2. I. Constitutional Definition

Every CDR shall begin by quoting the relevant Constitutional definition.

This section shall:
- Describe what the Constitution requires
- Never reference implementation
- Never infer from repository evidence
- Never change constitutional meaning

It is the **architectural destination**.

---

## 3. II. Repository Conformance Assessment

Immediately after the Constitutional Definition, every CDR shall include:

### Repository Conformance Assessment

For every constitutional property:

| Constitutional Property | Repository Evidence | Conformance |
|------------------------|-------------------|-------------|
| Property | Evidence | Full / Partial / None |

- **Repository Evidence** shall reference actual code.
- **Conformance** shall express only implementation status: Full / Partial / None.
- The repository shall never redefine the Constitution.

---

## 4. III. Constitutional Recommendation Discipline

Recommendations shall no longer state:

> Reality is...

Instead they shall state:

> The Constitution defines Reality as...
> Repository assessment indicates the current implementation is [Partial / Full / None].

The recommendation then explains how convergence reduces the gap.

---

## 5. IV. Constitutional Conformance Rating

Every recommendation shall include **two independent measurements**:

| Recommendation | Confidence | Constitutional Conformance |
|---------------|------------|---------------------------|

- **Confidence** answers: *How certain is the architectural conclusion?*
- **Constitutional Conformance** answers: *How closely does the current repository satisfy the Constitution?*

These measurements shall **never be merged**.

---

## 6. V. Constitutional Gap Statement

Every recommendation shall conclude with:

> **Constitutional Gap**
>
> Current implementation:
> <summary>
>
> Required constitutional state:
> <summary>
>
> Gap remaining:
> <summary>
>
> CEP objective:
> <summary>

The purpose of every CEP is to **reduce the Constitutional Gap**. Not merely modify code.

---

## 7. VI. Discovery Exit Criteria (Expanded)

Discovery is complete only when:

1. **Constitutional Definition is stated.**
2. **Repository Conformance is assessed.**
3. **Constitutional Gap is identified.**
4. **Repository Evidence supports every assessment.**
5. **Recommendations reduce the Constitutional Gap.**
6. **Confidence and Constitutional Conformance are independently reported.**
7. **No constitutional definition has been inferred from implementation.**

Until every condition is satisfied, implementation remains constitutionally prohibited.
