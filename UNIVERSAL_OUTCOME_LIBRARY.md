## Outcome Execution Sequence (Article III Example)

When a founder says "Create a five night Bali proposal":

```
1. IDENTIFY customer (search workspace memory)
2. SEARCH company knowledge (past Bali proposals)
3. SEARCH historical proposals (pricing, itineraries)
4. SEARCH internet if needed (current hotel rates, flight costs)
5. GENERATE itinerary (5 nights, suggested hotels, activities)
6. GENERATE quotation (itemized pricing)
7. GENERATE branded PDF (company branding)
8. SAVE proposal as Commitment(proposal)
9. LINK proposal to customer (Relationship)
10. CREATE follow-up task (7 days reminder)
11. PREPARE email draft for sending
12. NOTIFY founder with explanation
13. AWAIT approval for sending
```

Each step is an observable, auditable execution event per Z-06 Articles IV and IX.
