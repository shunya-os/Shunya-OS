## Implementation Path for Missing Mandatory Capabilities

The smallest changes to close each gap:

### 1. Searchability (Missing → Partial)
- **Backend:** Create a simple object search index (in-memory or SQL-based) that indexes object id, name, type, description. Add `/api/v1/objects/search?q=` endpoint.
- **Frontend:** Add search input to TopBar. Results appear inline.
- **Status change:** Missing → Partial (full search with relevance ranking is deferred)

### 2. Health (Missing → Partial)
- **Backend:** Add `health_score` field to RealitySnapshot per object. Compute from lifecycle stage + recent attention items + time since last event.
- **Frontend:** Show health indicator dot on LivingObjectCard.
- **Status change:** Missing → Partial (full health runtime is deferred)

### 3. Relationships (Partial → Complete)
- **Backend:** Create a standalone graph relationship endpoint (`/api/v1/objects/{id}/relationships`).
- **Frontend:** Add relationship browser to LivingObjectCard expansion.
- **Status change:** Partial → Complete

### 4. Lifecycle (Partial → Complete)
- **Backend:** Make lifecycle stages generic (configurable per object type, not hardcoded in demo data).
- **Frontend:** Lifecycle visualization already exists in LivingObjectCard.
- **Status change:** Partial → Complete

### 5. Permissions (Partial → Complete)
- **Backend:** Extend authz routes to support per-object permission queries.
- **Frontend:** Add permission indicator (owner, shared, public) to LivingObjectCard.
- **Status change:** Partial → Complete
