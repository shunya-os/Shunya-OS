## 1. Brand Essence

### 1.1 Core Identity

SHUNYA is an operating system for human organizations. It is not a tool, not a platform, not a dashboard — it is an operating system. This distinction governs every brand decision.

### 1.2 Brand Personality

| Trait | Manifestation |
|-------|---------------|
| **Calm** | Spacious layouts, minimal decoration, restrained motion |
| **Intelligent** | Perceptive, not obtrusive. Reveals what matters. |
| **Warm** | Paper-toned whites, gold accents, human-scale typography |
| **Authoritative** | Dark text as primary interactive colour, not blue |
| **Timeless** | Editorial typography, classic proportions, no trends |

### 1.3 Brand Archetype

The Sage (primary) + The Ruler (secondary). SHUNYA seeks understanding and brings order. It is not the Magician (no "delightful" experiences) and not the Caregiver (no "friendly" chatbot personality).

### 1.4 Brand Slogan

**"Think clearly. Operate intelligently."**

This is the primary marketing tagline. It appears on the landing page hero and in marketing materials. It is not the same as the identity tagline ("Infinite Intelligence. Zero Noise.") which is reserved for the hero artwork.

## 2. Brand Voice

### 2.1 Voice Principles

| Principle | Description |
|-----------|-------------|
| **Clear** | Short sentences. No jargon. Every word earns its place. |
| **Calm** | No urgency, no exclamation points, no "hurry" or "limited time." |
| **Confident** | No hedging ("we believe", "we think"). SHUNYA states facts. |
| **Warm** | Human, not corporate. Use contractions. Write for one person. |
| **Direct** | Say what SHUNYA does. Don't describe features; describe outcomes. |

### 2.2 Voice Examples

| ❌ Wrong | ✅ Right |
|----------|----------|
| "Leverage our cutting-edge AI platform to drive organizational synergy" | "Think clearly. Operate intelligently." |
| "Sign up for free and get started in minutes!" | "Get started →" |
| "We're excited to announce our new feature that helps you..." | "SHUNYA now surfaces real-time across your organization." |
| "Don't miss out on this limited-time offer" | (Never used) |

### 2.3 Writing for SHUNYA

- Use sentence case, not title case, for headings
- No exclamation marks in UI
- Use "you" and "your" (not "the user" or "the organization")
- Use "SHUNYA" (all caps) as the brand name
- Use "shunya" (lowercase) for the concept (Sanskrit: emptiness)
- Error messages are factual, not apologetic: "Sign in failed. Check your email and password." (not "Oops! Something went wrong.")

## 3. Wordmark Usage

### 3.1 Primary Wordmark

The SHUNYA wordmark consists of the text "SHUNYA" in Inter, weight 500, 13px, `--shunya-text`, accompanied by the gold dot.

```
● SHUNYA
```

### 3.2 Placement

| Surface | Position | Size |
|---------|----------|------|
| Navigation bar | Left side | 13px |
| Identity strip | Left side | 13px |
| Footer | Left side | 12px, weight 500 |
| Marketing materials | Top-left or center | Variable |

### 3.3 Clear Space

Minimum 8px on all sides of the wordmark. No other elements may touch the wordmark.

### 3.4 Minimum Size

- Digital: 11px font minimum
- Print: 8pt font minimum

### 3.5 Colour

- Always `--shunya-text` (#1a1c1d or #191b1c)
- Never white on dark backgrounds (no dark mode in v1.0)
- Never gold
- Never any other colour

### 3.6 Incorrect Usage

- ❌ SHUNYA in any colour other than `--shunya-text`
- ❌ SHUNYA in bold Playfair Display
- ❌ SHUNYA in all-lowercase ("shunya" for the wordmark)
- ❌ SHUNYA with a tagline next to it in the navigation
- ❌ SHUNYA without the gold dot in navigation/identity strip

## 4. The शून्य Mark

### 4.1 Sacred Usage

The शून्य mark is the most sacred brand element. It is used exclusively in the hero artwork. It is never used as a logo, favicon, watermark, or any other application.

### 4.2 Specifications

| Property | Value |
|----------|-------|
| Script | Devanagari |
| Text | शून्य |
| Font | Noto Sans Devanagari, weight 500 |
| Size | 36px (hero artwork) |
| Colour | `#1a1c1d`, opacity 0.78 |
| Letter-spacing | 0.06em |
| Animation | Gentle opacity pulse (0.76–0.82, 8s cycle) |

### 4.3 Clear Space

Minimum 40px on all sides. No ribbons, halos, or other elements may pass through the bounding box of the शून्य mark.

### 4.4 Prohibited Usage

- ❌ शून्य as a standalone favicon
- ❌ शून्य in any colour other than `#1a1c1d`
- ❌ शून्य in bold or italic
- ❌ शून्य in any font other than Noto Sans Devanagari
- ❌ शून्य outside the hero artwork context
- ❌ शून्य as a watermark or background pattern
- ❌ शून्य animated with anything other than the gentle opacity pulse

| Property | Value |
|----------|-------|

| Size | 5px (navigation, footer), 5px (identity strip), 6px (status dot) |
| Colour | `--shunya-gold` (#a4865f) |

### 6.2 Placement

The gold dot always accompanies the SHUNYA wordmark in navigational contexts. It sits to the left of the wordmark with an 8px gap.

```
● SHUNYA
```

### 6.3 Usage Rules

- ✅ Always accompanies the SHUNYA wordmark in navigation and footer
- ✅ Used as a section label marker on the landing page
- ❌ Never used as a bullet point for lists
- ❌ Never recoloured
- ❌ Never resized below 4px
- ❌ Never used without the wordmark in navigation

## 7. Hero Artwork

### 7.1 Canonical File

`static/img/artwork-hero.svg`

### 7.2 Dimensions

- ViewBox: 736 × 425
- Aspect ratio: 736:425 (approximately 1.73:1)
- Background: `#f8f6f2` (`--shunya-artwork-bg`)
- Border-radius: 20px

### 7.3 Layout Rules

- Desktop: Positioned to the right of hero text, occupying ~58% of the hero width
- Tablet: Below hero text, max-width 600px
- Mobile: Below hero text, full width

### 7.4 Animation Rules

- Ribbons undulate (20s, 18s, 22s cycles)
- Halos rotate (80s, 60s, 45s cycles)
- शून्य text gently pulses opacity (8s cycle, 0.76–0.82)
- All animation suspended on `prefers-reduced-motion: reduce`

### 7.5 Prohibited Usage

- ❌ Cropped to a different aspect ratio
- ❌ Used without the warm background (`#f8f6f2`)
- ❌ Used without the hero text block
- ❌ Rasterized (must remain SVG)
- ❌ Recoloured or modified in any way
- ❌ Used as a loading screen or splash screen
- ❌ Used as a standalone logo

## 8. Colour Identity

### 8.1 Brand Colours

| Colour | Hex | Role |
|--------|-----|------|
| Warm White | `#fbfaf8` | Page background |
| Pure White | `#ffffff` | Surface, cards |
| Near White | `#fefefe` | Navigation background |
| Artwork Beige | `#f3ebe2` | Artwork panel |
| Ink | `#1a1c1d` (or `#191b1c`) | Primary text, interactive elements |
| Gold | `#a4865f` | Identity accent |
| Gold Light | `#d4c0a8` | Hover state, light accent |

### 8.2 Colour Hierarchy

```
Background (warm white) ──── Surface (white) ──── Text (ink)
     │                           │                      │
     │                           │                      └── Primary interactive colour
     │                           │
     │                           └── Card, modal, input surfaces
     │
     └── Gold = identity, section labels, artwork
```

### 8.3 Prohibited Colour Usage

- ❌ No blue as an interactive colour (the old #2563eb is deprecated)
- ❌ No green accent buttons or CTAs
- ❌ No red as a primary colour
- ❌ No purple, orange, or teal decorative colours
- ❌ No colour gradients in UI elements (gradients are for artwork only)
- ❌ No dark mode in v1.0

## 9. Typography Identity

### 9.1 Brand Typography

| Role | Font | Weight | Usage |
|------|------|--------|-------|
| Display | Playfair Display | 400, 400 italic | Headlines, hero, section headings |
| Body | Inter | 200–600 | Everything else |
| Mono | SF Mono / Fira Code | 400, 600 | Code, data |
| Devanagari | Noto Sans Devanagari | 300–600 | शून्य mark only |

### 9.2 Typography as Identity

Typography is SHUNYA's strongest visual asset. The combination of Playfair Display (editorial, warm, human) and Inter (functional, clear, modern) communicates the brand's duality: timeless intelligence meets modern capability.

### 9.3 Prohibited Typography

- ❌ No bold Playfair Display
- ❌ No system fonts (Arial, Times New Roman) in any UI
- ❌ No Google Fonts other than the three specified
- ❌ No web-safe fallbacks that differ significantly from the primary font
- ❌ No font-size below 10px in any UI context

## 10. Tone of Voice

### 10.1 Writing Principles

| Principle | Example |
|-----------|---------|
| **Direct** | "Sign in to continue." (not "You can sign in to continue to your workspace.") |
| **Calm** | "Your workspace is ready." (not "Let's get started! 🚀") |
| **Clear** | "Check your email and password." (not "There seems to be an authentication issue.") |
| **Human** | "What's on your mind?" (not "Please enter your query.") |

### 10.2 UI Copy Patterns

| Context | Pattern |
|---------|---------|
| Empty state | "No items yet. Create your first [item] to get started." |
| Error | "[Action] failed. [Reason]. [Next step]." |
| Success | "[Action] completed." |
| Confirmation | "Are you sure you want to [action]?" |
| Loading | "Loading..." (not "Fetching data..." or "Please wait...") |

### 10.3 Prohibited Copy

- ❌ Emojis in UI text (🚀, 📊, ✅)
- ❌ Exclamation points in UI
- ❌ Corporate jargon (leverage, synergy, optimize, utilize)
- ❌ Anthropomorphizing AI ("I think", "I believe", "I'm learning")
- ❌ Urgency language (hurry, limited time, act now, don't miss)
- ❌ Superlatives (best, greatest, revolutionary, game-changing)

## 12. Prohibited Usage

### 12.1 Never Do These

| Element | Prohibition |
|---------|-------------|
| **Logo** | Never use the शून्य mark as a logo |
| **Colours** | Never introduce blue, purple, or green as interactive colours |
| **Typography** | Never use bold Playfair Display |
| **Motion** | Never use spinning loaders, confetti, parallax, or decorative animations |
| **Icons** | Never use emoji as icons |
| **Photography** | Never use stock photography on SHUNYA surfaces |
| **Illustration** | Never introduce a conflicting illustration style |
| **Dark mode** | Never implement dark mode without Founder approval |
| **Gradients** | Never use colour gradients in UI (artwork only) |
| **Borders** | Never use borders heavier than 1px rgba(26,28,29,0.07) |

### 12.2 Visual Contamination

SHUNYA's visual identity is contaminated by the presence of any of these elements:

- Bootstrap-style blue buttons
- Tailwind utility classes for colours (use CSS variables)
- Emoji navigation icons
- Dense data tables with alternating row colours
- Spinning loading spinners
- "Card with shadow" default patterns
- Any element that makes the experience feel like a generic SaaS product

### 12.3 Audit Requirement

Any new surface, partnership integration, or expansion must undergo a brand identity audit before launch. The audit checks:

1. Palette compliance (no new colours)
2. Typography compliance (no new fonts or sizes)
3. Component compliance (reuses existing patterns)
4. Identity compliance (शून्य, tagline, gold dot rules)
5. Motion compliance (no decorative animation)
6. Copy compliance (brand voice, no emoji, no exclamation marks)

## 14. Brand Extensions

### 14.1 SHUNYA Sub-brands

No sub-brands in v1.0. All products and features are simply "SHUNYA" with a descriptive modifier:

- SHUNYA Workspace (the authenticated environment)
- SHUNYA Intelligence (the AI layer)
- SHUNYA Identity (the authentication system)
- SHUNYA Memory (the knowledge store)

### 14.2 Partnership Branding

When SHUNYA is integrated with a partner:

- SHUNYA wordmark + gold dot appears at the same size as the partner's mark
- No совместно (co-branded) logos
- No शून्य mark in partnership contexts
- No tagline in partnership contexts

### 14.3 Third-party Use

No third party may use the शून्य mark, the tagline, or the hero artwork without explicit written approval. The SHUNYA wordmark and gold dot may be used with attribution.
