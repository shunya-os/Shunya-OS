# SHUNYA Knowledge Vault

> Permanent institutional memory for SHUNYA.
> Foundational material that is not source code but too important to leave on a server.

This directory is SHUNYA's permanent knowledge vault. It preserves foundational material — research, decisions, vision, architecture thinking, and constitutional history — that is versioned, reviewable, and never stranded on a single machine.

## Structure

```
knowledge/
├── founder/               — Founder's vision, principles, directives
├── research/              — Research artifacts, analysis, explorations
├── product/               — Product strategy, positioning, market analysis
├── ai/                    — AI/ML research, model decisions, inference architecture
├── architecture/          — Architecture decisions, trade-off analyses, system design
├── decisions/             — Major decisions with context, alternatives, and rationale
├── vision/                — Long-term vision documents, strategic direction
└── constitutional-history/ — History of constitutional amendments and governance evolution
```

## Principles

1. **Durable** — Knowledge here is foundational. It is not ephemeral task output.
2. **Versioned** — All content is versioned through Git. No knowledge is lost.
3. **Reviewable** — Every entry is structured for review by the Founder and future stewards.
4. **Referenced** — Knowledge entries may be referenced by code, architecture decisions, and constitutional documents.
5. **Append-only** — Corrections are new entries with forward references, not modifications to existing entries.

## Usage

- Add entries as Markdown files with clear titles and dates.
- Cross-reference relevant constitutional sections, ADRs, and other knowledge entries.
- Keep entries factual and structured. This is institutional memory, not a journal.
