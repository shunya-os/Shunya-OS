Security & RBAC Audit

  • Signin: Passwords validated via TeamMember.check_password(). Wrong passwords rejected. Unregistered emails rejected with 404.
  • Authorization: All FOR2 API endpoints enforce role checks. _check_role() requires minimum role level for each operation.
  • Organization Isolation: Members can only access their own orgs. api_list_organizations returns only the user's memberships.
  • Department Isolation: Managers see only their department members. Staff see only themselves.
  • API Security: All endpoints check authentication before returning data. Credential stuffing prevented by password validation.
