# Purpose

This document records significant engineering and architectural decisions made during the evolution of the Shunya Platform.

Unlike ADRs, which explain *why* a specific architectural decision was made, the Decision Log provides a chronological overview of platform evolution.

Every major milestone should have an entry in this document.

# Decision Policy

Every significant platform decision should satisfy the following:

- Documented

- Reviewed

- Approved

- Traceable

If a decision changes platform architecture, it must also be documented through an ADR.
