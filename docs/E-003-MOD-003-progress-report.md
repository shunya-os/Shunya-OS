## Temporal Edge Types (§5.2)

| Type | Derivation | Behaviour |
|------|-----------|-----------|
| **CURRENT** | No validity, or start ≤ now ≤ end | Active now |
| **FUTURE** | start > now | Predicted to be true |
| **EXPIRED** | end < now (generic edge type) | Was true, no longer |
| **SUPERSEDED** | end < now (superseded_by/version_of) | Replaced by newer truth |
| **HISTORICAL** | Manual classification | Was true in the past |
| **SCHEDULED** | Detected via `is_scheduled()` | Definite future time |

## Temporal Queries (§5.4)

| Query | Description |
|-------|-------------|

| `changes(T1, T2)` | Change events (created/activated/expired/removed) in range |
| `future(T)` | Edges predicted to be active at T |
