## APPENDIX: What To Expect From The Audience

### Likely questions and how to answer:

**"How is this different from an ERP?"**
> ERP systems integrate existing departments. SHUNYA replaces the concept of departments. There is no "accounting team" — accounting is just what happens when you invoice someone.

**"How long did this take to build?"**
> The platform foundations were built in weeks, not years. The architecture exists to add any new capability without rewriting existing ones.

**"What about my existing data?"**
> SHUNYA connects to existing systems through canonical APIs. Legacy data is migrated once and becomes part of the single truth.

**"Is this only for travel companies?"**
> The demo used a corporate offsite because it's easy to understand. SHUNYA has zero travel-specific code. Every capability is domain-agnostic.

### Smooth recovery lines if something fails:

**If a call takes longer than expected:**
> "SHUNYA is thinking. The more data it has, the faster it gets."

**If an error appears:**
> "That's the system telling us something interesting. Let me show you how the error itself becomes knowledge."

**If search returns unexpected results:**
> "Every search is a discovery. The more you use SHUNYA, the better it understands what matters to you."
