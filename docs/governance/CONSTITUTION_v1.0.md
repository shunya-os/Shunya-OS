## Framework Architecture

```
CG-0A  ───  Governance of the Constitution (meta-governance)
CG-1  ───  Architectural Discipline
  └── CG-1A  Constitutional Consistency & Platform Continuity
CG-2  ───  Design Partnership & Architectural Challenge
  └── CG-2A  Continuous Architectural Learning & Constitutional Evolution
CG-3  ───  Strategic Evolution & Platform Roadmap Governance
CG-4  ───  Definition of Excellence & Completion
```

## Implementation Workflow

Every implementation follows this order:

```
1. Load constitutional-architecture-reflection skill
2. CG-3:  Strategic sequencing — should this be built now?
3. CG-1:  Architecture Reflection Report (17 sections)
4. CG-1A: Constitutional consistency review
5. CG-2:  Architectural challenge — alternatives, abstraction check
6. CG-2A: Learning review, pattern detection, mistake prevention
7. Code
8. CG-4:  Completion review — excellence audit, pride test, nothing-more test
9. CG-2A: Future engineer guidance
10. Commit with evidence
```

## Audit Cadence

- **Per-phase:** Verification evidence in every commit message
- **Per-milestone:** Constitutional Compliance Audit (CA-1 format)
- **Per-major-version:** Governance Health Report

## Governance Freeze

Effective CR-1, no new constitutional directives shall be introduced unless:
1. A Constitutional Consistency Audit identifies a genuine governance gap
2. A Constitutional Compliance Audit demonstrates an existing directive is ineffective
3. Platform evolution requires a fundamental capability not covered by the current framework

All future governance changes default to amendments (XA) under the existing structure.
