# Universal Architecture

SHUNYA is built around universal business concepts.

Not applications.

Not modules.

Not industries.

Everything inside SHUNYA ultimately becomes one or more universal objects connected through relationships.

The operating system understands the business through these relationships.

Objects are the atomic units of the operating system.

Objects are persistent.

Objects evolve.

Objects possess identity.

Objects never exist independently of context.
