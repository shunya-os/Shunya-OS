# Purpose

Artificial Intelligence should never reason from isolated prompts.

It should reason from complete organizational context.

The AI Context Engine assembles every piece of information required before any reasoning begins.

The quality of intelligence depends directly upon the quality of context.

---

# Design Goals

The AI Context Engine shall provide:

Automatic context assembly.

Universal context contracts.

Permission-aware context.

Memory integration.

Knowledge integration.

Timeline integration.

Relationship traversal.

Workspace awareness.

Explainable reasoning.

Provider independence.

---

# Definition

Context is the complete set of organizational information required for a reasoning task.

Context is assembled.

Never manually written.

Never permanently stored.

Every reasoning request receives a fresh contextual view.
