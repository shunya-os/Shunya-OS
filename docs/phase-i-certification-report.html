1. Root Cause

The original SSEStreamManager and EventBus were both process-local singletons per Gunicorn worker. When Worker A emitted an event, it was delivered only to subscribers on Worker A. SSE clients connected to Worker B never received events.

2. Architecture

Transport: Redis Pub/Sub via RedisEventRelay class.

Worker A:
  Event → Local EventBus → RedisEventRelay → Redis Pub/Sub
                                              ↓
Worker B:
  RedisEventRelay → Local EventBus → SSEStreamManager → SSE Client

No competing event architecture was introduced. Redis was already in production for rate limiting, sessions, and cache.

6. Signup Routing Fix

Bug: The fallback auth handler used window.history.replaceState + setPhase('login') instead of window.location.href, which only changed the URL bar without triggering a page load. When clicking "Create Account," the URL changed to /auth/signup but the sign-in form remained.

Fix: Changed to window.location.href = '/auth/signup' (full page navigation) in frontend/src/app.tsx:346.

Similar issue scan: Only this one instance found. The "Forgot password" link already used the correct pattern.
