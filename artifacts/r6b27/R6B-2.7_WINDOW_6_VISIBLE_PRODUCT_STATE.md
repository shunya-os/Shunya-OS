## BLOCK D — DOCUMENT INTELLIGENCE LOOP

**What visibly changed:** opening a document in the Documents workspace now shows
a **Document Intelligence** panel: the identified class, a confidence figure, the
content signals that produced it, the extracted entities (people/amounts/dates/
emails/phones/references/organisations), an explicit empty state, an
"Identify document" action when unanalysed, "Re-identify", and truthful failure
with Retry.

Loop: REAL DOCUMENT → INGESTION (`/api/v1/founder/ingest`) → IDENTIFICATION
(`app/document/classification.py`, deterministic + explainable + business-agnostic)
→ PERSISTENT RESULT (`Document.classification` + `structured_data.intelligence`)
→ VISIBLE USER STATE (frontend panel) → CONTEXTUAL AVAILABILITY
(`GET .../documents/<id>/intelligence`, tenant/uploader-scoped).

Truthfulness: content with no business-document signal returns `unknown` at
`0.0` confidence — never a confident guess. Classification uses the document's own
text only (company data first); no internet retrieval. Document content is treated
as data, not authority.

Also fixed: the amount extractor did not recognise `$` or `€` (only ₹/Rs/INR/USD/
EUR/£), so USD/EUR invoices yielded no amounts. Now recognises `$`, `€`, `GBP`.
