# R6B-2.7 — WINDOW 6 · PRODUCTION READ-BYPASS CLASSIFICATION

Scope: every production read of the canonical object store (`sh_objects`) that does
NOT go through `core/object_service.py`, plus the write paths that bypass it.
Method: repository-native static inspection only (no ad-hoc interpreter probes).
Runtime facts used: `requirements.txt` pins `SQLAlchemy>=2.0,<3.0`; installed
`.venv` dist-info = **SQLAlchemy 2.0.36**. In 2.0 a plain `str` passed to
`Session.execute()` raises `ObjectNotExecutableError`
(`sqlalchemy/engine/base.py:1416`, verified in the installed source). Therefore a
**plain-string** `db.session.execute("SELECT ...")` is non-executable: it can never
return rows. It is classified DEAD, not a live leak.
