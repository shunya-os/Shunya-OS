# CP-01 — SHUNYA Capability Universe

**Permanent Implementation Backlog**
**Date:** 2026-08-05
**Classification:** Strategic — not a roadmap, not a specification. A universe of capabilities SHUNYA may eventually provide.

---

## Classification Guide

| Label | Meaning |
|---|---|
| **Native** | SHUNYA builds this as a first-party capability. Core to the OS identity. |
| **Integrated** | SHUNYA delegates to a mature free engine/API/service and provides a Living Object interface. |
| **Replaceable** | SHUNYA could replace an existing tool category. High differentiation opportunity. |
| **Never Build** | Not SHUNYA's domain. Delegate entirely to existing best-in-class tools. |

Every capability below is expressed in terms of:
- **Living Object** — the object type(s) involved
- **Execution Domain** — the runtime that powers it
- **Cognition** — how AI enhances it

No capability is defined as belonging to a screen or panel.

## IV. Strategic Summary

### By Classification

| Classification | Count | Strategic Role |
|---|---|---|
| **Native** | 43 | Build everything — defines SHUNYA's identity |
| **Integrated** | 12 | Delegate to free engines — focus on Living Object interface |
| **Replaceable** | 1 | Document collaboration — SHUNYA could replace Google Docs |
| **Never Build** | 0 | Every capability is either native or integrated |

### Priority Distribution

| Priority | Count | Target | When |
|---|---|---|---|
| **P0** | 8 | Launch-critical | Already partially implemented |
| **P1** | 25 | Phase 1 | Next implementation wave |
| **P2** | 20 | Phase 2 | After Phase 1 |
| **P3** | 14 | Phase 3 | Long-term vision |

### Key Strategic Decisions

1. **Search (#17-19)** — The single most impactful capability not yet built. Meilisearch is free, self-hosted, and can index everything in under a day.

2. **Communication (#24-28)** — SHUNYA should not build its own email client, calendar, or chat. These are mature categories. SHUNYA should integrate and surface them as Living Objects.

3. **Files (#45-50)** — MinIO (S3-compatible) is free and self-hosted. File operations should be Living Objects, not a separate file browser.

4. **Intelligence (#51-58)** — SHUNYA's differentiation. Free LLMs already connected. Every observation, prediction, and recommendation is a Living Object.

5. **Automation (#34, #58)** — This is where SHUNYA becomes an operating system rather than a tool. "When X happens, do Y" on any Living Object.
