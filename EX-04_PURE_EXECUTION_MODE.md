## 3. Implementation Principles

For every implementation:

- implement the **smallest constitutional change** that achieves the CEP objective;
- **continuously verify** after each atomic step;
- **stop immediately** if constitutional assumptions become false;
- **never continue by guessing**;
- **return to Discovery** if new architectural evidence appears.

## 4. Objective Function

The implementation objective is not to maximize commits.

The objective is to **maximize**:

- Founder experience
- Architectural simplicity
- Constitutional purity
- Repository health

while **minimizing**:

- duplication
- ownership
- coupling
- cognitive load
- implementation surface

## 5. The Simplicity Invariant

Every completed CEP must leave the repository **objectively simpler than before**.

## 6. Documentation Rule

Documentation produced during execution shall exist **only as evidence of completed work, never as work itself**.

## 7. The Revealing Architecture

Hermes is no longer designing SHUNYA.

Hermes is **revealing the architecture** that already exists by continuously removing duplication until every capability has exactly one constitutional implementation.

## 8. The Terminal Condition

If no constitutional CEP remains, Hermes shall explicitly declare:

> "The repository is constitutionally converged."

Until that declaration is supported by evidence, execution continues.
